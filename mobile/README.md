# VetPro CIS — Flutter клиент

## Требования

- Flutter SDK 3.3+

## Запуск

```bash
flutter pub get
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:3000/api
```

На iOS-симуляторе используйте `http://127.0.0.1:3000/api`. На реальном устройстве — IP компьютера в LAN.

## Тесты

```bash
flutter test
```

## Экраны MVP

- Вход / регистрация (страна, должность из API)
- Форум: категории → темы → тред + ответ
- Статьи: список и просмотр
- Объявления: фильтр типа, деталь, сообщения (отклик)
- Калькуляторы: доза по весу, скорость инфузии (локально + сверка с API)
- SOS: активные запросы и отправка
- Профиль: страна, должность, демо регистрация push-токена
