# UX: ключевые экраны мобильного приложения VetPro CIS

Дизайн-система: материал 3, крупные зоны нажатия, тёмная тема опционально.

## Навигация (нижний bar)

1. **Лента** — объединённая лента: форум + статьи (переключатель сегментов) или отдельные вкладки внутри.
2. **Объявления** — вакансии / куплю / продам.
3. **Инструменты** — калькуляторы.
4. **SOS** — выделенная вкладка + плавающая кнопка на главных экранах (длинное нажатие / подтверждение).
5. **Профиль** — настройки, страна, должность, выход.

## Экраны по модулям

### Авторизация
- Splash → Выбор «Вход / Регистрация».
- Регистрация: email, пароль, страна (picker), город (text), должность (picker), чекбокс согласия.
- Вход: email + пароль; «Забыли пароль» — post-MVP.

### Профиль
- Аватар, имя, страна (флаг + название), должность, город.
- Бейдж верификации (статус).
- Список «Мои темы», «Мои объявления», «Закладки статей».

### Форум
- Список категорий (карточки).
- Список тем в категории (pull-to-refresh, пагинация).
- Тема: заголовок, автор, страна, теги, посты; поле ответа закреплено внизу.
- Создание темы: категория, заголовок, текст, теги.
- Меню поста: «Пожаловаться».

### Статьи
- Список рубрик / все статьи.
- Деталь: заголовок, дата, автор, HTML/markdown body (упрощённо).
- Иконка закладки.

### Объявления
- Фильтр чипами: Все | Вакансии | Куплю | Продам | Мой регион.
- Карточка: тип, заголовок, регион, дата.
- Деталь: описание, кнопка «Откликнуться» → экран чата по объявлению.

### Калькуляторы
- Список калькуляторов.
- Экран калькулятора: поля ввода, кнопка «Рассчитать», блок дисклеймера всегда видим.

### SOS
- Экран предупреждения + кнопка «Продолжить».
- Форма: краткий текст, вид животного (chips), срочность (low/med/high), чекбокс «Поделиться регионом».
- Список активных SOS (опционально для модерации/волонтёров) — отдельный режим или вкладка «Помощь».

## Состояния
- Пустые списки: иллюстрация + CTA.
- Ошибка сети: retry.
- Загрузка: skeleton для списков.

## Доступность
- Минимальный контраст WCAG AA.
- Крупный шрифт для полей ввода в калькуляторах.
