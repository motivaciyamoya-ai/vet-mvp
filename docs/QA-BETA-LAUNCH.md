# QA, бета и подготовка релиза MVP

## 1. Чеклист перед бета-тестом

### Инфраструктура
- [ ] Подняты Postgres и Redis (`backend/docker-compose.yml`).
- [ ] Применены миграции: `npx prisma migrate deploy` (prod) или `migrate dev` (dev).
- [ ] Выполнен seed на staging: `npm run seed`.
- [ ] Заданы сильные `JWT_*_SECRET` в `.env`, не используются дефолты.
- [ ] HTTPS на edge (reverse proxy / cloud).

### Backend
- [ ] `GET /api/health` возвращает `ok`.
- [ ] Swagger `/api/docs` доступен только на non-prod или за VPN.
- [ ] Регистрация/логин, refresh/logout.
- [ ] Форум: категории, темы, ответы.
- [ ] Статьи: список, деталь, создание под ролью модератора/админа.
- [ ] Объявления и сообщения.
- [ ] SOS + регистрация push (заглушка логирует рассылку).
- [ ] Калькуляторы: совпадение результатов с юнит-тестами.

### Mobile
- [ ] `API_BASE_URL` указывает на доступный с устройства хост (`lib/core/config.dart` или `--dart-define`).
- [ ] Вход демо-пользователем, навигация по всем вкладкам без крашей.
- [ ] `flutter test` проходит.

## 2. Автотесты

**Backend:** из `vet-mvp/backend` выполнить `npm test` (Jest, формулы калькуляторов).

**Mobile:** из `vet-mvp/mobile` выполнить `flutter test`.

## 3. Мониторинг и стабильность

- Подключить Sentry/Crashlytics для mobile и backend (ошибки + performance).
- Логи API в stdout/агрегатор (ELK, Grafana Loki, CloudWatch).
- Алерты на 5xx и на деградацию `health`.

## 4. Бета-группа

- 20–50 ветеринаров из 2–3 городов, NDA/согласие на обработку данных.
- Сбор обратной связи: форма + чат модераторов.
- Метрики: регистрации, посты, SOS, retention D1/D7.

## 5. Критерии выхода в store (MVP)

- Нет блокирующих дефектов по PRD приёмке.
- Политики privacy/terms опубликованы (юридически выверенные).
- Модерация и жалобы обрабатываются вручную в согласованный SLA.
