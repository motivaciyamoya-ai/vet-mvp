# Юридические шаблоны

Перед публикацией приложения подготовьте с юристом и адаптируйте под вашу организацию:

- `terms-of-use.md` — пользовательское соглашение
- `privacy-policy.md` — обработка персональных данных
- `medical-disclaimer.md` — отказ от ответственности за медицинские рекомендации

Тексты в этом каталоге не являются юридической консультацией и должны быть проверены/адаптированы.
