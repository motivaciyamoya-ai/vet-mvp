# PRD: VetPro CIS — мобильный MVP для ветеринарных специалистов

**Версия:** 1.0  
**Регион запуска:** СНГ (русскоязычная аудитория)  
**Платформа:** iOS / Android (Flutter)  
**Монетизация:** отсутствует в MVP

---

## 1. Цели продукта

1. Дать ветеринарам единое место для профессионального общения, обмена опытом и быстрых консультаций.
2. Снизить время поиска информации: статьи, калькуляторы, типовые сценарии.
3. Поддержать карьеру и оборот оборудования: вакансии и объявления покупка/продажа.
4. Обеспечить канал экстренной помощи коллегам (SOS) с уведомлениями.

**Метрики успеха MVP (4–8 недель после релиза):**
- DAU/WAU ≥ 0.25 среди зарегистрированных активных пользователей.
- ≥ 30% пользователей совершают ≥ 2 ключевых действия (пост / статья / объявление / калькулятор / SOS).
- Среднее время ответа в SOS-треде ≤ 15 мин (медиана, в рабочие часы, на пилотной группе).

---

## 2. Целевая аудитория

- Врачи ветеринарной медицины, зоотехники с ветобразованием, ассистенты клиник.
- Студенты ветфаков (ограниченный функционал: чтение, без публикации без верификации — опционально post-MVP).

---

## 3. Роли и права

| Роль | Описание |
|------|----------|
| **Гость** | Не авторизован: ограниченный просмотр (настраивается политикой). |
| **Специалист** | Полный пользовательский функционал MVP. |
| **Модератор** | Жалобы, скрытие контента, блокировки по правилам. |
| **Админ** | Справочники (страны, должности), пользователи, системные настройки. |

**Верификация специалиста (MVP):** статус в профиле «на проверке / подтверждён / отклонён»; загрузка документа — post-MVP или упрощённо через поддержку.

## 4. User flows (кратко)

### 4.1 Регистрация и профиль
1. Ввод email/пароля или телефона (если включено).
2. Выбор страны, города, должности из справочника.
3. Пополнение профиля (ФИО/ник, клиника — опционально).
4. Согласие с условиями и политикой.

### 4.2 Форум
1. Список категорий → тема → ответы.
2. Создание темы с тегами и вложениями.
3. Жалоба на пост/тему → очередь модерации.

### 4.3 Статьи
1. Каталог / рубрики / поиск.
2. Чтение статьи, закладка.
3. Публикация (роль «редактор» или админ в MVP — через API/seed; полный редакторский UI — post-MVP).

### 4.4 Вакансии и маркет
1. Лента объявлений с фильтром типа: вакансия | продам | куплю.
2. Карточка объявления → отклик → переписка (чат по объявлению).

### 4.5 Калькуляторы
1. Выбор калькулятора → ввод параметров → результат + дисклеймер.
2. История расчётов локально на устройстве (опционально в MVP).

### 4.6 SOS
1. Удержание / подтверждение SOS (защита от случайного нажатия).
2. Создание срочного запроса (текст, вид животного, срочность, гео — опционально).
3. Уведомление подписчикам SOS / ближайшим по региону (логика MVP: broadcast по стране + push-токены).

## 5. Функциональные требования MVP

### 5.1 Аккаунт
- Регистрация, вход, выход, refresh-токены.
- Профиль: страна, город, должность, аватар (URL или upload post-MVP).

### 5.2 Форум
- Категории, темы, посты, пагинация.
- Теги (строка или M2M — в схеме БД).
- Жалобы: тип, цель (thread/post), статус.

### 5.3 Статьи
- Статьи с рубрикой, статусом публикации, full-text поиск (минимум — по заголовку/анонсу в MVP API).

### 5.4 Объявления
- Тип объявления, заголовок, описание, регион, контакт (внутри приложения через отклик).
- Отклики и сообщения в контексте объявления.

### 5.5 Калькуляторы
- Клиентские расчёты + опциональный endpoint для валидации параметров.
- Дисклеймер: не замена очной консультации и назначению врача.

### 5.6 SOS
- Создание запроса, смена статуса (open / in_progress / resolved).
- Push: регистрация FCM-токена, рассылка при новом SOS (упрощённо).

---

## 6. Нефункциональные требования

- **Безопасность:** HTTPS, хэш паролей (bcrypt), JWT + refresh, rate limiting на auth и SOS.
- **Надёжность:** структурированные логи, health-check, миграции БД.
- **Производительность:** пагинация, индексы на внешние ключи и частые фильтры.
- **Юридическое:** пользовательское соглашение, дисклеймер медконтента, политика персональных данных (шаблоны в `docs/legal/` — заглушки).

---

## 7. Критерии приёмки MVP

- [ ] Регистрация/вход, профиль с страной и должностью из справочников.
- [ ] CRUD тем/постов форума с категориями; жалоба создаётся и видна модератору (API).
- [ ] Список и деталь статьи; поиск возвращает релевантные результаты.
- [ ] Объявления с типами; отклик создаёт чат-тред сообщений.
- [ ] Минимум 2 калькулятора в приложении с тестами формул.
- [ ] SOS: создание, список активных, push-token сохраняется.
- [ ] Docker Compose поднимает API + Postgres + Redis; README описывает запуск.

---

## 8. Вне скоупа MVP

- Оплата внутри приложения, реклама, подписки.
- Видеоконсультации, интеграция с МИС.
- Полноценный CMS для статей в мобильном UI.
- Юридически значимая верификация диплома без ручного процесса.

---

## 9. Зависимости и интеграции

- Firebase Cloud Messaging (или аналог) для push — конфиг через env.
- S3-совместимое хранилище для вложений — post-MVP; в MVP — URL или отсутствие файлов.

---

## 10. Риски

| Риск | Митигация |
|------|-----------|
| Медицинская ответственность за советы | Дисклеймеры, модерация, запрет рекламы сомнительных препаратов в правилах. |
| Токсичный контент / спам | Rate limits, жалобы, роль модератора. |
| Злоупотребление SOS | Подтверждение жестом, лимиты, блокировка при злоупотреблении. |
